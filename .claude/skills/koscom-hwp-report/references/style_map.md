# 코스콤 보고서 블록 카탈로그 (style map)

base 템플릿 `templates/summary_base.hwp`, `templates/detail_base.hwp`에는 블록마다 원형이 하나씩 들어 있다.
렌더러(`Composer`)는 원형을 복제한 뒤 `{{이름}}` 자리를 채운다. 이때 구간마다 글자모양은 그대로 유지된다.
블록 위치(문단 번호)는 `templates/*_catalog.properties`가 정본이다. 이 문서는 사람이 읽는 설명서다.

- 재생성: `java TemplateBuilder <요약 Template.hwp> <상세 Template.hwp> templates`
- 값이 없는 placeholder가 든 구간은 통째로 빠진다. 예를 들어 `LABEL`이 없으면 `(라벨) ` 구간이 사라진다.
- 단위: 글자 크기는 pt이다. 문단모양의 들여쓰기·여백은 **파일 저장값 = HWPUNIT × 2**이다(1pt = 100 HWPUNIT).

## 1. 공통 본문 블록 (요약·상세 동일 구조)

| 블록 | 원형 텍스트 (구간별 글자모양) | 글꼴 | 문단모양 |
|---|---|---|---|
| `H1` 대제목 | `{{MARK}} {{TEXT}}` — MARK는 ``(□) 또는 `1.` | 함초롬바탕 16 Bold | 기본(160%) |
| `O` 1단계 | `  ㅇ ` + **`({{LABEL}}) `** + `{{TEXT}}` | 함초롬바탕 15 / 라벨 Bold | 내어쓰기 −7500 |
| `NUM` 1단계(원문자) | **`  {{NUM}} {{TEXT}}`** — NUM은 ①②③ | 함초롬바탕 15 Bold | 내어쓰기 −7500 |
| `DASH` 2단계 | `    - ` + **`({{LABEL}}) `** + `{{TEXT}}` | 함초롬바탕 15 / 라벨 Bold | 내어쓰기 −9000 |
| `DOT` 3단계 | `      · {{TEXT}}` | 함초롬바탕 15 | 내어쓰기 −11500 |
| `NOTE` 각주 | `      * {{TEXT}}` | 함초롬돋움 12 | 내어쓰기 −9800 |
| `REF` 참고 | `     ※ {{TEXT}}` | 함초롬돋움 12 | 내어쓰기 −9000 |
| `GAP4/6/8/10/12` | 빈 문단 | 함초롬바탕 4·6·8·10·12 | 기본 |

내어쓰기 값을 정한 기준: 둘째 줄이 머리 기호 다음 글자에 맞도록 했다. 공백은 0.5em, 한글은 1em으로 계산했다.
쇼케이스(`work/showcase_*.hwp`)를 뷰어로 열어 다섯 단계 모두 맞는 것을 확인했다.

### 간격 규칙 (템플릿 안내 주석 기준)

| 위치 | 간격 블록 |
|---|---|
| 제목 박스 → 첫 대제목 | `GAP10` |
| 대제목 → ㅇ, ㅇ → ㅇ | `GAP8` |
| ㅇ → - | `GAP6` |
| - → ·, ㅇ → *, · → ※ | `GAP4` |
| 대제목 묶음 사이 | `GAP12` |

| 블록 | 구조 | placeholder |
|---|---|---|
| `COVER_FULL` (문단 24개) | 로고, 제목(3×1 표, HY헤드라인M 32), 날짜(휴먼명조 24 Bold), 본부/부서(2×1 표, HY헤드라인M 24), 담당자 박스. 빈 문단으로 한 쪽을 채운다. | `TITLE`, `DATE`, `HQ`, `DEPT`, `담당`, `팀장`, `부장` |

| `CHAPTER` | 1×1 표 `{{ROMAN}}. {{TEXT}}`, HY헤드라인M 18, 아래 파란 선. 쪽 나눔이 설정되어 있다. | `ROMAN`, `TEXT` |
| `PART` | 1×3 표 `[{{NUM}}](흰 글씨·남색 배경) [여백] [{{TEXT}}](HY헤드라인M 17, 회색 배경)` | `NUM`, `TEXT` |

상세보고 본문 순서: `CHAPTER → GAP4 → PART → GAP8 → H1(1. 개요) → GAP8 → O …`

## 4. 박스·표·첨부 (요약·상세 공통)

| 블록 | 구조 |
|---|---|
| `BOX` 강조 박스 | 노란 배경 1×1 표. 셀 안 원형은 `box.TITLE`(`<{{TITLE}}>`), `box.TITLE_GAP`, `box.O`(`ㅇ {{TEXT}}`), `box.GAP`, `box.DASH_GAP`, `box.DASH`(`  - {{TEXT}}`), `box.REF`(`※ {{TEXT}}`). 글꼴은 함초롬돋움 15. 높이는 내용에 맞춰 줄고, **쪽 경계에서 나누지 않는다**. |
| `TABLE1` 격자형 / `TABLE2` 좌우 개방형 | 3×4 원형. 행 원형은 `table.ROW_HEAD`(함초롬돋움 13 Bold, 회색), `ROW_MIDDLE`, `ROW_LAST`(Type 2는 아래 굵은 선)이다. `TableBuilder`가 원형 칸 9종(행 역할 3 × 열 역할 3)을 복제해 행·열 수와 너비, 병합을 자유롭게 구성한다(P3). 첫 본문 행이 아닌 칸은 위쪽 선을 가는 선으로 바꾼 테두리 변형을 쓴다. 쪽이 넘어가면 행 단위로 나누고 머리행을 반복한다. |
| `ATTACH` / `REFBOX` | 1×3 표 `[첨부](흰 글씨·남색) [여백] [{{TEXT}}](HY헤드라인M 16)`. 쪽 나눔이 설정되어 있다. |
| `DOTBOX` | 참고 내용을 담는 점선 1×1 표. 셀 안에 본문 블록 복제본을 넣는다. 글자는 위쪽에 붙고, 높이는 내용에 맞춘다. |

## 5. 렌더러 구현 규칙 (P0·P1에서 확인)

1. 텍스트를 바꾼 문단은 LineSeg를 지운다. `HwpOps.setRuns`가 처리한다.
2. 문단 끝 문자(0x0D)는 **정확히 하나**만 둔다. `ParaText.addString`은 끝 문자를 스스로 붙이지만, 글자 단위로 추가할 때는 붙지 않는다. 빠지거나 중복되면 파일이 깨지거나 빈 줄이 생긴다.
3. 글자가 없는 빈 문단은 텍스트 레코드를 두지 않는다. hwplib는 빈 글자 목록을 쓰지 못한다.
4. 표·도형·구역 정의 같은 확장 컨트롤 문자는 텍스트를 바꿀 때도 보존한다. 컨트롤을 지울 때는 대응하는 문자도 함께 지운다(`removeControl`).
5. 구역 정의(`SECTION`)는 조립한 첫 문단 앞으로 옮긴다. 별도 문단으로 두면 빈 줄 하나가 생겨 표지가 다음 쪽으로 밀린다.
6. 표 행을 추가할 때는 열마다 해당 역할 행(중간/마지막)의 테두리를 따른다. 테두리/배경 번호는 **1부터** 센다(목록 위치 + 1).
7. 병합 칸은 시작하는 행의 `Row`에만 넣고, 덮이는 칸은 만들지 않는다(행별 칸 수 = `cellCountOfRow`).
8. 결과 파일은 `tools/checkopen.ps1`로 뷰어가 실제로 여는지 확인한다(OK/FAIL).

## 6. 알려진 한계 / 다음 단계 과제

- 날짜·부서 칸 너비가 고정이라 `2026. 10. 23, 금융영업1팀`처럼 길면 두 줄이 된다 → P2에서 길이를 경고하거나 날짜 형식을 줄인다.
- 표지 제목이 두 줄이 되면 정식 표지가 한 쪽을 넘을 수 있다 → P4에서 빈 문단 수를 조정한다.
- ~~점선 박스 안 글자가 테두리에 붙음~~ → P2 렌더러에서 위아래 GAP4를 넣어 해결.
- ~~표 열 4개 고정~~ → P3에서 해결(열 수·너비·병합·정렬 자유).
- 그림(이미지) 블록은 아직 없다 → P4에서 BinData를 추가한다.
- 강조 박스는 템플릿 기준 함초롬돋움 15이다. 상세 샘플은 박스 안에 함초롬바탕 15를 썼다. 필요하면 선택지로 둔다.

# 코스콤 보고서 작성 원칙 (개조식)

출처: 코스콤 보고서 표준 양식 템플릿의 `<작성 원칙>` 박스와 Sample(요약·상세) 문서.
사용자가 준 메모·회의록·초안을 report.json으로 옮기기 **전에** 이 원칙대로 다듬는다.

## 1. 템플릿의 작성 원칙 (그대로 지킨다)

- 본문은 핵심 내용 중심으로 간결하게 작성한다 — **한 항목 3줄 이내**
- 문장은 가독성을 고려해 단어 단위로 줄을 바꾼다. 렌더러가 자간으로 줄 끝 걸침을 막지만, 근본적으로는 문장을 짧게 쓴다.
- 불필요한 서술과 중복 표현은 쓰지 않는다
- 단계는 `□ > ㅇ(또는 ①) > - > ·` 순서로 구성하고, **'ㅇ 단계' 중심**으로 쓴다

## 2. 문장 끝맺음

보고서는 문장이 아니라 **명사형·개조식**으로 끝낸다.

| 피할 것 | 쓸 것 |
|---|---|
| 조직문화를 개선하는 방안을 수립하였습니다. | 조직문화 개선방안 수립 |
| 직원 간 소통을 활성화하고자 합니다. | 직원 간 소통 활성화 도모 |
| 해외 출장을 실시할 예정입니다. | 해외 출장 실시 예정 |
| 검토가 필요한 상황입니다. | 검토 필요 |
| ~하는 경우도 있습니다. | ~하는 경우도 있음 |

자주 쓰는 끝맺음: `~ 수립`, `~ 실시`, `~ 추진`, `~ 도모`, `~ 마련`, `~ 제고`, `~ 강화`, `~ 반영`, `~ 필요`, `~ 예정`, `~ 완료`, `~함`, `~음`

## 3. 라벨 `(구분)`

ㅇ·- 항목 앞에 2~6자 라벨을 붙이면 훑어 읽기 쉽다. Sample도 대부분의 항목에 라벨을 붙였다.

- `(활동 기간) 2024. 8. 19 ~ 2025. 7. 22(약 12개월)`
- `(활동 인원) 총 11명(위원 10명*, 간사 1명)`
- 같은 묶음 안에서는 라벨 성격을 맞춘다: 기간/인원/예산, 현황/문제점/개선방안, 개인/부서

라벨은 `label` 키에 괄호 없이 넣는다. 렌더러가 괄호를 붙이고 굵게 만든다.

## 4. 숫자·날짜 표기

| 항목 | 표기 |
|---|---|
| 날짜 | `2026. 4. 23`(마침표 뒤 한 칸). 상세보고 표지는 `2026.3` |
| 기간 | `2024. 8. 19 ~ 2025. 7. 22(약 12개월)` |
| 금액 | `12억원`, `3,500만원` |
| 비율·증감 | `90%`, `전년 대비 12%↑` |
| 인원 | `총 12명(의장 1, 부의장 1, 위원 10)` |

## 5. 강조·각주·참고

- `**굵게**`는 한 항목에 한두 곳, 핵심 구절에만 쓴다. 남발하면 강조 효과가 사라진다.
- 본문 단어 뒤에 `*`를 붙이고(`10명*`), 그 항목의 `children`에 `note`로 설명을 단다 → 위첨자 * + 각주 줄.
- `ref`(※)는 그 묶음의 시사점, 판단 기준, 출처처럼 본문과 성격이 다른 한 줄에 쓴다.

## 6. 구성

### 요약보고 (1~2쪽)
- 대제목(□) 2~4개, 묶음마다 ㅇ 2~4개
- 결과보고 예: `□ 개요 → □ 주요 내용(실적) → □ 성과 → □ 향후 계획`
- 계획보고 예: `□ 추진 배경 → □ 추진 내용 → □ 추진 일정 → □ 기대 효과`
- 세부 자료는 `첨부`(본문 형식)나 `참고`(점선 박스)로 뒤에 붙인다

### 상세보고 (표지·목차가 있는 기획서·가이드)
- 템플릿 목차 예: `I. 추진 배경 → II. 추진 현황(1. 시장 현황 / 2. 경쟁사 현황 / 3. 당사 현황) → III. 기본 방향 → IV. 추진 과제(1. 과제 …) → V. 기대 효과 → <별첨>`
- 장(I, II) 아래에 절(1, 2)을 두고, 절 아래에 `1. 개요`, `2. 세부 내용` 같은 대제목을 둔다
- 장이 짧으면 절 없이 바로 대제목을 둔다(`sections`)

## 7. 표

- 열은 4~7개, 머리행 칸은 2~6자로 짧게 쓴다
- 칸 안 문장은 한두 줄로 쓴다. 길면 `\n`으로 의미 단위에서 줄을 나눈다
- 같은 값이 세로로 이어지면 `^`로 병합한다(예: 같은 기수·부서)
- 비교표는 Type 1(격자), 실적·현황 목록은 Type 2(좌우 개방)가 원본 샘플의 관례다

## 8. 하지 말 것

- 원문에 없는 수치·사실을 지어내지 않는다. 비어 있으면 사용자에게 묻거나 `○○` 자리표시로 둔다.
- 결재라인에 사람 이름을 지어 넣지 않는다. 모르면 `○○○(내선)`으로 둔다.
- 존댓말 서술문(~합니다)으로 쓰지 않는다.

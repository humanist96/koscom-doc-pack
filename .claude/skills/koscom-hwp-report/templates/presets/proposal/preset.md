# 제안서·공모전 기획서

새 아이디어를 설득해야 할 때 쓴다. 계획보고가 "하기로 한 일"을 보고한다면, 제안서는 "왜 이것을 해야 하는가"를 설득한다. 그래서 현황 분석과 차별점, 기대 효과의 근거가 중요하다.

## 구성(장)

| 장 | 쓸 내용 |
|---|---|
| I. 제안 배경 | 문제 인식(현장의 불편·비용), 추진 필요성(정책·시장·사내 환경 변화) |
| II. 현황 분석 | 사내외 유사 사례, 기존 방식의 한계, 시사점 → 차별화 방향(강조 박스) |
| III. 제안 개요 | 명칭, 한 줄 정의, 구조 그림, 핵심 차별점 비교표 |
| IV. 추진 내용 | 기능·과제별로 절([1], [2]…)을 나눠 상세히 |
| V. 추진 계획 | 준비 상태, 단계별 일정 **표**, 필요 자원 |
| VI. 기대 효과 | 정량 효과 표(값·근거·성격), 정성 효과, 파일럿 지표 |
| 별첨 | 공모전이면 **심사 기준 대응표**, 예상 질문과 답변, 리스크 |

## 표·그림

- 차별점: `구분 / 내용 / 기존 방식과의 차이`(격자형)
- 정량 효과: `항목 / 값 / 근거 / 성격`. 성격 칸에 `실측·외부 자료·가정·계산`을 구분해 적는다
- 그림은 장마다 1개 이내. 코쇠 삽화를 쓸 때는 흰 여백을 잘라 넣는다(가로형 110~140mm)

## 작성 규칙

- 표지 제목은 한 줄 약 13자, 2줄 이내. 부제를 넣으려면 `명칭 : 한 줄 설명` 형식으로 한 문장에
- 코쇠 삽화는 `scripts/crop_image.py`로 흰 여백을 잘라 넣는다
- 외부 수치(벤더 발표, 언론 보도)는 출처와 성격을 밝히고, 직접 잰 값을 앞에 둔다
- 공모전 심사 기준이 있으면 별첨 대응표에서 항목별로 근거 장을 적는다
- 표 칸은 한 줄 12~14자 안쪽으로 짧게, 열 너비는 지정하지 않는다(자동)

# 사업계획서·기획서

코스콤 상세보고 템플릿의 원래 목차(추진 배경 → 추진 현황 → 기본 방향 → 추진 과제 → 기대 효과)를 그대로 쓰는 정식 기획 문서다. 본부장 이상 보고, 연간·중장기 계획, 큰 신규 사업에 쓴다. 공모전·아이디어 제안이면 `proposal`이 더 맞다.

## 구성(장)

| 장 | 쓸 내용 |
|---|---|
| I. 추진 배경 | 외부 환경(정책·시장·기술·고객), 내부 필요성 |
| II. 추진 현황 | 절로 나눔: [1] 시장 현황 [2] 경쟁사 현황 [3] 당사 현황 |
| III. 기본 방향 | 비전·목표, 추진 전략(강조 박스로 요약) |
| IV. 추진 과제 | 과제별 절. 과제 요약 **표**(과제 / 내용 / 일정 / 담당) |
| V. 기대 효과 | 정량 목표, 정성 효과 |
| 별첨 | 세부 일정, 소요 예산, 참고 자료 |

## 작성 규칙

- 장이 짧으면 절 없이 바로 대제목을 둔다(`sections`)
- 목표 수치는 기준 연도와 목표 연도를 함께: `2026년 120억원 → 2028년 160억원`
- 경쟁사는 사용자가 준 표기대로. 예시·시험에서는 `A사`
- 목차 쪽번호는 추정값이므로 뷰어 캡처로 확인한다
- 표지 제목은 한 줄 약 12자, 2줄 이내. 렌더러 경고가 없어도 표지가 두 쪽으로 넘치지 않았는지 캡처로 확인한다

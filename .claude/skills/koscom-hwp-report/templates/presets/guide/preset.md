# 업무 가이드·매뉴얼

업무 절차와 기준을 문서로 남겨 누구나 같은 방식으로 처리하게 할 때 쓴다. 코스콤 상세보고 샘플(경영계획 수립 가이드)이 이 형태다. 표지는 한 쪽에 제목·장 목차·날짜를 함께 두는 간략형(`compact`)이 기본이다.

## 구성(장)

| 장 | 쓸 내용 |
|---|---|
| I. 작성 목적 | 왜 이 가이드가 필요한가, 적용 범위. 절차 전체 그림 1개 |
| II. 절차별 가이드 | 절차마다 절([1], [2]…). 각 절은 `1. 개요`(시기·주체·주요 내용) → `2. 세부 내용`(① 단계) |
| III. 유의 사항 | 자주 하는 실수, 예외 처리, 문의처 |
| 별첨 | 서식, 체크리스트, 일정표 |

## 표·그림

- 절차 요약표: `단계 / 하는 일 / 주체 / 산출물`(좌우 개방형)
- 절차 흐름 그림은 I장에 1개. 그림이 없으면 요약표로 대신한다
- 원칙·기준은 강조 박스(`box`)로 묶는다

## 작성 규칙

- 각 단계는 `num`(①②) 항목으로, 단계 아래 `-`에 할 일을 적는다
- 주체(누가)와 시기(언제)를 빠뜨리지 않는다
- 규정 조항을 인용하면 규정명과 조항 번호를 `※`로

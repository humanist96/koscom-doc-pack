# 결과보고

끝난 일의 결과를 팀장·부서장에게 올릴 때 쓴다. "무엇을 했고(개요·내용) → 얼마나 됐고(성과) → 다음은 무엇인가(향후 계획)" 순서다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 개요 | 기간, 대상·범위, 방식, 담당 | (기간) (대상) (방식) |
| 주요 내용 | 실제로 한 일. 단계·회차·과목별로 나눠 ㅇ 2~4개 | (1단계) (교육 내용) |
| 성과 | 수치 실적은 **표**로. 목표 대비, 전년 대비 증감 | (실적) (만족도) |
| 향후 계획 | 미흡 사항의 보완, 다음 회차, 확산 계획과 일정 | (보완) (확산) |

## 표

- 성과 표: `구분 / 목표 / 실적 / 달성률 / 비고` 또는 `구분 / 전년 / 금년 / 증감`. 좌우 개방형(style 2)
- 증감은 `5.2%p↑`, `12명↓`처럼 화살표로 쓴다

## 작성 규칙

- 첫 대제목에서 결과를 한 줄로 먼저 말해도 좋다(예: "(결과) 이수율 96.4%, 전년 대비 5.2%p 상승")
- 원문에 없는 수치·비율은 계산할 수 있을 때만 쓰고, 계산식이 맞는지 다시 확인한다
- 미흡한 점이 있으면 숨기지 않고 성과 아래 `-`나 `※`로 적고, 향후 계획에서 보완책을 낸다

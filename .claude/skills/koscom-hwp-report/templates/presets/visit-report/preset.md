# 고객 방문 결과 보고

영업·고객지원 담당이 고객사를 만난 뒤 결과를 보고할 때 쓴다. 회의 결과 보고와 비슷하지만 **고객이 원하는 것**과 **우리가 할 일**을 분리해 적는다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 방문 개요 | 일시, 고객사, 참석(고객 측·당사), 목적 | (일시) (고객사) (참석) (목적) |
| 주요 논의 | 고객 현황, 당사 제안·설명 내용 | (고객 현황) (당사 설명) |
| 고객 요청 사항 | 요청을 하나씩 ㅇ으로, 기한이 있으면 함께 | (요청 1) |
| 후속 조치 | 조치 / 담당 / 기한 **표** | |

## 작성 규칙

- 고객사명은 사용자가 준 표기대로 쓴다. 예시·시험 문서에서는 `A증권`처럼 쓴다
- 고객 측 참석자는 직급과 부서까지만, 개인 연락처는 넣지 않는다
- 가격·계약 조건은 확정된 것과 협의 중인 것을 분명히 나눈다

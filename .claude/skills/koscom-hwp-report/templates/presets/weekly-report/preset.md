# 주간 업무 보고

매주 반복해서 올리는 한 장짜리 보고다. 표 중심으로 짧게 쓰고, 읽는 사람이 손을 써야 할 것은 **이슈 및 건의**에 따로 모은다.

## 구성

| 대제목 | 쓸 내용 |
|---|---|
| 금주 실적 | 업무 / 내용 / 진행률(또는 상태) **표** |
| 차주 계획 | 업무 / 내용 / 일정 **표** |
| 이슈 및 건의 | 지연·위험·결정이 필요한 사항. 없으면 "특이 사항 없음" |

## 표

- 금주 실적: `구분 / 업무 / 진행` (진행 칸: `완료`, `70%`, `지연`)
- 차주 계획: `구분 / 업무 / 일정`
- 행이 많아도 한 쪽을 넘기지 않는다. 넘치면 중요한 업무만 남긴다

## 작성 규칙

- 지난주 차주 계획에 있던 업무가 이번 주 실적에서 빠지면 지연 사유를 이슈에 쓴다
- 날짜는 `11. 10(월)`처럼 요일을 붙인다

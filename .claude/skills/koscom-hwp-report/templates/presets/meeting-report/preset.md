# 회의 결과 보고

회의가 끝난 뒤 결과를 윗선에 보고하거나 참석자와 공유할 때 쓴다. 발언을 옮겨 적는 회의록이 아니라 **무엇을 정했고 누가 언제까지 하는가**를 남기는 보고다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 회의 개요 | 일시, 장소, 참석(인원 또는 부서), 안건 | (일시) (참석) (안건) |
| 주요 논의 | 안건별 ㅇ, 쟁점과 의견은 `-` | (안건 1) |
| 결정 사항 | 확정된 것만. 보류·추가 검토는 `※`로 구분 | (결정 1) |
| 후속 조치 | 할 일 / 담당 / 기한 **표** | |

## 표

- 후속 조치 표: `조치 사항 / 담당 / 기한`(좌우 개방형)

## 작성 규칙

- 참석자 실명은 사용자가 준 경우에만 쓰고, 많으면 "부서 6명"처럼 줄인다
- 누가 무슨 말을 했는지보다 의견의 내용을 쓴다("~ 의견 제시")
- 결정되지 않은 것을 결정 사항에 넣지 않는다

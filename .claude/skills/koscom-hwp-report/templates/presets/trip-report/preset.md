# 출장 결과 보고

출장을 다녀와 결과를 보고할 때 쓴다. 일정 나열에서 끝나지 않고 **우리 회사에 주는 시사점**과 **다음에 할 일**까지 쓰는 것이 핵심이다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 출장 개요 | 기간, 장소, 출장자, 목적 | (기간) (장소) (출장자) (목적) |
| 주요 활동 | 일자별 일정 **표** + 핵심 내용 ㅇ | (면담) (세션) |
| 시사점 | 배운 점, 우리 사업에 적용할 점 2~3개 | (시장) (기술) |
| 후속 조치 | 자료 공유, 추가 협의, 검토 과제 | (공유) (검토) |

## 표

- 일정 표: `일자 / 방문처·행사 / 주요 내용`(좌우 개방형)

## 작성 규칙

- 출장자 실명은 사용자가 준 표기대로. 많으면 "○○팀 2명"
- 비용 정산은 이 보고에 넣지 않는다(사용자가 요청하면 참고로 한 줄)
- 외국 기관명은 처음 한 번 원어 병기

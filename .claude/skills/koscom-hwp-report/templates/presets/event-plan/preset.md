# 행사 계획 보고

행사를 열기 전에 계획을 보고하고 승인받을 때 쓴다. 당일 진행표(시간표)와 누가 무엇을 맡는지가 핵심이다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 행사 개요 | 행사명, 일시, 장소, 참석 규모, 목적 | (일시) (장소) (참석) (목적) |
| 세부 일정 | 당일 시간표 **표** | |
| 역할 분담 | 업무 / 담당 / 비고 **표** | |
| 소요 예산 | 항목별 금액, 합계, 집행 근거 | (대관) (다과) (합계) |
| 준비 일정 | D-day 기준 준비 순서 | (D-14) (D-7) |

## 표

- 시간표: `시간 / 내용 / 비고`(좌우 개방형). 시간은 `14:00 ~ 14:10`
- 역할 표: `업무 / 담당 / 비고`

## 작성 규칙

- 외부 귀빈·기관 참석자는 사용자가 준 표기대로. 예시·시험에서는 `A기관`
- 예산 금액은 `350만원`처럼 쓰고 합계가 맞는지 다시 계산한다
- 우천·불참 등 대비책이 있으면 마지막에 `※`로

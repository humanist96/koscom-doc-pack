# 계획보고

앞으로 할 일을 보고하고 승인받을 때 쓴다. 기획서보다 짧고(1~2쪽), 표지·목차가 없다. 분량이 많거나 장(I, II…)이 필요하면 `business-plan`(상세보고)을 쓴다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 추진 배경 | 왜 지금 필요한가: 현황·문제, 외부 요구, 지시 사항 | (현황) (문제점) (필요성) |
| 추진 내용 | 무엇을 하나: 과제별 ㅇ, 세부는 `-` | (과제 1) (대상) (방법) |
| 추진 일정 | 단계·월별 일정 **표** | |
| 기대 효과 | 정량(시간·비용·건수)과 정성 효과, 소요 예산이 있으면 함께 | (정량) (정성) (예산) |

## 표

- 일정 표: `단계 / 주요 내용 / 일정 / 담당` (좌우 개방형). 분기·월 칸에 `●`를 찍는 간트형도 쓸 수 있다
- 예산이 있으면 기대 효과 아래 `※ 소요 예산: …` 한 줄 또는 별도 표

## 작성 규칙

- 결재권자가 결정할 사항(승인 요청, 선택지)이 있으면 마지막 대제목 끝에 `※`로 분명히 적는다
- 효과 수치가 추정이면 "약", "예상"을 붙이고 근거를 각주로 단다

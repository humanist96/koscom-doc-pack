# 교육 기획안

교육 과정을 새로 열거나 바꿀 때 기획해 보고한다. 교육이 끝난 뒤의 보고는 `result-report`를 쓴다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 교육 개요 | 과정명, 목적, 대상·인원, 일시·장소, 방식(집합·온라인) | (목적) (대상) (일정) (방식) |
| 교육 내용 | 차시별 커리큘럼 **표** | |
| 운영 계획 | 모집 방법, 강사, 이수 기준, 만족도 조사 | (모집) (강사) (이수 기준) |
| 소요 예산 | 강사료·교재·대관 등 항목과 합계 | (항목) (합계) |

## 표

- 커리큘럼: `차시 / 주제 / 주요 내용 / 시간`(좌우 개방형)

## 작성 규칙

- 외부 강사는 사용자가 준 표기대로, 미정이면 "외부 강사(섭외 중)"
- 실습이 있으면 준비물(노트북, 계정 등)을 운영 계획에 적는다

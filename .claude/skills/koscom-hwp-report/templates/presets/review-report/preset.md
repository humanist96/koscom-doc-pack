# 검토보고

누군가의 요청이나 제안, 제도 변경안을 검토해 "하자/말자/이렇게 하자"를 건의할 때 쓴다. 핵심은 **대안 비교표**와 **분명한 건의**다.

## 구성

| 대제목 | 쓸 내용 | 라벨 예 |
|---|---|---|
| 검토 배경 | 누가 무엇을 요청·제안했나, 검토 범위 | (요청 내용) (검토 범위) |
| 현황 | 지금 어떻게 하고 있나, 관련 규정·계약·수치 | (현행) (관련 규정) |
| 검토 의견 | 대안 2~3개 비교 **표** + 판단 근거 | (대안 비교) (검토 결과) |
| 건의 사항 | 무엇을 결정해 달라는가, 후속 조치 | (건의) (후속 조치) |

## 표

- 대안 비교표: `구분 / 1안 / 2안 / (3안)` 열, 행은 `내용 / 장점 / 단점 / 비용·영향`. 격자형(style 1)
- 추천안은 표 머리 칸에 `2안(추천)`처럼 표시한다

## 작성 규칙

- 건의 사항은 첫 ㅇ에서 결론을 한 문장으로: "(건의) 2안으로 시행 건의"
- 대외 고객이 관련되면 고객사 이름 대신 `A사`처럼 쓰거나 사용자가 준 표기를 그대로 쓴다
- 비용·수익 영향은 추정이면 "약"을 붙이고 산식을 각주로

본부장 보고용으로 "생성형 AI 활용 업무혁신 추진계획"을 표지랑 목차 있는 상세보고서로 만들어줘(한글 hwp, 코스콤 상세보고 양식).
디지털혁신본부 / AI전략팀이고, 담당 한지수(7201) / 팀장 오세훈(7200) / 부장 윤가람(7000), 2026.11 로 해줘.

내용은 이렇게 4개 장으로:

I. 추진 배경
- 금융권 생성형 AI 도입이 빠르게 늘고 있음 (국내 증권사 10곳 중 7곳이 사내 AI 비서 도입 또는 시범 운영 중)
- 우리 회사도 보고서 작성, 고객 문의 응대, 코드 리뷰 등 반복 업무 비중이 큼 (직원 설문: 업무시간의 32%가 반복 문서 작업)
- 단, 금융보안 규정상 고객정보·원장 데이터는 외부 AI로 보낼 수 없음

II. 추진 현황
 1. 사내 현황 - 7월부터 AI 코딩 도구 시범 운영(개발자 40명), 코드 리뷰 시간 25% 단축 / 사내 문서 검색 챗봇은 PoC 완료
 2. 타사 사례 - A증권: 리서치 요약 자동화, B은행: 상담 내용 요약, C거래소: 공시 검토 보조

III. 추진 과제
 1. 업무 자동화 - 보고서 서식 자동 작성, 회의록 요약, 계약서 검토 보조 (2027년 1분기 오픈)
 2. 고객 지원 - 고객 문의 1차 응대 챗봇 (개인정보 마스킹 후 처리, 2027년 2분기)
 3. 거버넌스 - AI 사용 가이드라인 제정, 부서별 AI 담당자 지정, 분기별 사용 실태 점검

IV. 기대 효과
- 반복 문서 작업 시간 30% 절감 목표 (연간 약 4만 시간)
- 고객 문의 응답 시간 단축 (평균 4시간 → 1시간 이내)
- 단계별 일정은 표로 정리해줘: 과제 / 1분기 / 2분기 / 3분기 / 4분기 (2027년 기준, 진행 분기에 ● 표시)

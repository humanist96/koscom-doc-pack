3분기 금융영업 실적 요약보고 한글(hwp)로 부탁해. 코스콤 서식 그대로. 표도 꼭 넣어줘.
금융영업1팀, 담당 박민수(5101) / 팀장 정다은(5100) / 부서장 최준호(5000), 날짜는 2026. 10. 15.

1) 실적 요약
- 3분기 신규 계약 14건, 계약금액 합계 38.6억원 (목표 35억원 대비 110%)
- 증권사 대상 클라우드 원장 서비스가 9건으로 제일 많음
- 해지 1건 (소형 자산운용사, 내재화 사유)

2) 지점별 실적 (표로)
권역 / 담당 / 신규 건수 / 계약금액(억원) / 목표 대비
수도권 / 1팀 / 6 / 17.2 / 115%
수도권 / 2팀 / 4 / 10.1 / 101%
지방 / 부산 / 3 / 8.3 / 119%
지방 / 대구 / 1 / 3.0 / 75%
→ 수도권 두 줄은 권역 칸 하나로 합치고, 지방도 마찬가지로 합쳐줘.

3) 4분기 계획
- 대구 권역 부진 원인 파악(10월 중 현장 방문)하고 지역 증권사 2곳 추가 제안
- 클라우드 원장 서비스 레퍼런스 사례집 만들어서 영업에 활용 (11월)

참고로 뒤에 "주요 계약 목록"을 참고 자료로 붙여줘: A증권(클라우드 원장, 6.5억), B증권(시세 API, 4.2억), C자산운용(백오피스, 3.1억).
